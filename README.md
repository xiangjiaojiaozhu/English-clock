# English Clock Mobile

First Android build-channel test for the mobile port of English Study.

## Build
GitHub Actions automatically builds a debug APK on every push to `main`.
Download it from **Actions → Build Android APK → Artifacts → EnglishClock-debug-apk**.

## Current test
This first build only verifies the APK pipeline and HarmonyOS 4 installation path. Full English Study features come after this build succeeds.
